What this does
A two-step job application tool built on the Claude API.

Step 1 — Screen: Paste a job description and get an instant match score (1-10), verdict (apply / review before applying / pass), salary recommendation, fit reasons, identified gaps, and a plain-language summary. Scoring uses calibrated rules that distinguish between role families, flag hard disqualifiers like procurement/sourcing roles or engineering domain requirements, and avoid false positives from title matches alone.

Step 2 — Tailor (optional, score 5+): Generates a tailored resume and cover note based on your stored resume and the job description. Also flags any claims worth pressure-testing for accuracy before submitting.

Using this tool: Enter your Anthropic API key (get one at console.anthropic.com), configure your resume and optional custom scoring rules in the Resume & rules tab, then paste any job description and screen it. Each screening costs roughly $0.005-0.01. Resume + cover note generation adds another $0.01-0.02.

Customizing for your own use
This tool is designed to be repurposed by other job seekers.

The DEFAULT_RESUME and DEFAULT_RULES constants near the top of the source file are the only things you need to change. Replace DEFAULT_RESUME with your own resume text. Replace DEFAULT_RULES with scoring guidance tailored to your background, target roles, and known gaps. Everything else stays the same.
